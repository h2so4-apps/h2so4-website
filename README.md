# H2SO4 Website

H2SO4の公式サイトです。アプリ紹介、サポート、プライバシーポリシー、広告・アフィリエイト方針を掲載します。

## Pages

- `/` — H2SO4 トップ
- `/apps/kumocalc` — 雲電卓（KumoCalc）
- `/apps/furumane` — ふるマネ
- `/support` — サポート・問い合わせ
- `/privacy/kumocalc` — 雲電卓 プライバシーポリシー
- `/privacy/furumane` — ふるマネ プライバシーポリシー
- `/advertising` — 広告・アフィリエイトについて

## Local development

```bash
npm install
npm run dev
```

本番用ビルドは `npm run build` で作成できます。
